# TimeHUD Rust Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Python/PyQt6 TimeHUD overlay as a single Rust binary with full behavioral parity, a compatible config, and a more polished look, at a fraction of the startup time and memory.

**Architecture:** One binary, two process roles. The **HUD process** (default) is a single-threaded `poll()` loop over the X11 connection, an IPC Unix socket and a signal pipe. It draws the overlay, popup menus and tray icon in software with `tiny-skia` + `fontdue` and pushes the pixels to override-redirect ARGB X11 windows via `x11rb`. There is no GL and no toolkit. The **settings process** (`timehud settings …`) is an `eframe`/egui window spawned on demand. It talks to the HUD over the same socket, so egui/GL memory is only paid while settings is open. All behavior lives in platform-free modules (`engine`, `config`, `themes`, `app`, `menu`, `layout`) that are unit-tested headless. The X11 glue is thin.

**Tech Stack:** Rust 2024 edition, `x11rb` (features: `randr`, `shape`), `tiny-skia`, `fontdue`, `serde`/`serde_json`, `chrono` (local clock), `clap` (derive), `nix` (poll, signal-safe pipe), `signal-hook`, `rodio` (wav/mp3/vorbis/flac), `eframe` (default-features off; `glow`, `x11`, `default_fonts`). Add every dependency with `cargo add <crate>` so you get the current release, rather than pinning versions from this plan.

**Spec:** `docs/superpowers/specs/2026-11-11-rust-port-design.md`. Read it fully before Task 1. The Python source of truth is at `/home/ben/repo/timehud`, and many tasks say "port X from file Y". Read that file, because its logic and tests are the spec.

## Global Constraints

- Linux/X11 only. Always connect to X11 (`DISPLAY`), never Wayland. `--wayland` prints `warning: --wayland is ignored; TimeHUD runs as an X11 client` to stderr and continues.
- Config path `$XDG_CONFIG_HOME/timehud/config.json`, default `~/.config/timehud/config.json`. Existing keys, names, types and defaults must stay exactly as in `src/timehud/config.py`. A Rust-saved file must still load in the Python app.
- Timer semantics and beep timing are identical to `src/timehud/timer_engine.py`, including the quirks listed in spec §6.3. A ported test that "looks wrong" is still right.
- The Classic theme's values must stay identical to Python's.
- Version `0.9.0`. `Cargo.toml` is the only source, read via `env!("CARGO_PKG_VERSION")`.
- Global hotkeys are off by default (`""`). Grabs are exclusive X11 grabs.
- Performance targets: launch to visible overlay < 150 ms, idle RSS of the HUD process < 40 MB, ~0% CPU while paused.
- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test` pass at the end of every task.
- Commit after every task, with messages ending in the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Stale socket after a crash.** A leftover `timehud.sock` with no listener must not stop a new HUD from starting, or make it think another instance is running. → test in Task 11.
2. **Saved position off-screen** (monitor unplugged, resolution changed). The overlay must be clamped back into the current work area at startup instead of being invisible. → test in Task 4.
3. **`sound_file` set but undecodable or missing.** The app must fall back to the built-in beep, with no panic and no silence. → test in Task 9.
4. **`font_family` not installed** (e.g. Glass's "Noto Sans" missing). The bundled JetBrains Mono must be used. → test in Task 5.
5. **Config dir not writable.** Saving must fail with a logged warning while the HUD keeps running. → test in Task 2.

- `from_value` rules: start from `Config::default()`. For each known key present, deserialize that field alone. On a type error, keep the default for that field only. An integer field rejects JSON bools and floats (matching Python's `_is_int` strictness for presets; for plain fields, floats fall back to default). Unknown keys go into `extra`. `to_value` writes `extra` first and then known fields, so known fields win.
- `valid_presets` mirrors Python `valid_presets` exactly: name must be a string, `last5`/`boundary`/`halfway` must be bools when present, ints are non-bool and ≥ the minimum, and interval presets need `total >= work`.

### Task 14: HUD event loop

**Files:**
- Create: `src/hud.rs`
- Modify: `src/main.rs` (wire `run_hud`)

**Interfaces:**
- Consumes: everything above.
- Produces: `pub fn run_hud(cfg: Config, listener: UnixListener, no_tray: bool) -> anyhow::Result<()>`
- Loop: `nix::poll` over the X fd, the listener, every client `Conn` and the signal-hook pipe (SIGINT, SIGTERM), with timeout = `min(app.next_wakeup, 16 ms if animating, save-debounce deadline, 1 s for sound.idle_release)`. Each iteration drains X events (`poll_for_event`), routing them to the popup if open, otherwise the tray or the overlay → `app.handle`. It then runs `app.tick` when due, applies `Effect`s, and if `Redraw` (or animating) calls `app.frame` → `present`. `Resize`/`Move` lead to `set_geometry(app.window_pos(), layout size)`.
- Effects: `Beep` → `sound.play`. `SaveSoon` → arm 300 ms debounce. `SaveNow` → save immediately (log errors to stderr and keep running). `SetClickThrough` → `set_click_through`. `SetVisible` → map/unmap (on map also raise). `SetTrayVisible` → `tray.set_visible` (unless `no_tray`). `OpenMenu` → `MenuPopup::open(build_menu(...))`, and a `Chosen(action)` → `app.perform`. `OpenSettings{tab}` → if a settings child is connected send `Event::Focus{tab}`, else spawn `current_exe() settings [--tab tab]`. `OpenSavePreset` → spawn `current_exe() save-preset`. `Notify(text)` → spawn `notify-send TimeHUD <text>` and ignore errors. `Quit` → save, ungrab, exit 0.
- IPC requests: `Toggle`/`Reset`/`Show`/`Hide`/`ToggleVisibility`/`Quit` → the matching `App` method and reply `Ok`. `SettingsHello` → store this conn as the settings conn, take `snapshot = app.cfg.clone()`, reply `Config{config, tab}`. `Preview{config}` → `app.preview_config(Config::from_value(..))`. `Commit{config}` → preview + `SaveNow`, and the snapshot is dropped. `Cancel`, or EOF on the settings conn without Commit → `app.preview_config(snapshot)` + `SaveNow` (parity: closing the window = Cancel). `SavePreset{name}` → `app.save_preset`.
- Hotkeys: after start and after every `Preview`/`Commit`, call `grabs.set` from the three `hotkey_*` fields, and send any failures back to the settings conn as `Event::Error`. A KeyPress matching a grab → the `App` action.
- On any Left/Middle press on the overlay, call `overlay.focus()` so the local keys (Space, R, Escape, Ctrl+Q) work afterwards.
- Reap settings and notify children with `waitpid(WNOHANG)` each loop iteration.
- Startup order (for < 150 ms): connect X → load fonts → `App::new` → create the window → present the first frame → *then* create the tray and grabs.
